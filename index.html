Autodromo Nazionale Monza IoT Simulator 2.0

Application of IoT in Motorsport: End-to-End Race Car Telemetry Pipeline, Virtual Sensor Network & Intelligent Race Engineering Analytics

PROJECT OVERVIEW: Demonstrating the complete Internet of Things (IoT) lifecycle in Formula 1 motorsport at the iconic 5,793m Autodromo Nazionale Monza ("Temple of Speed"). This platform models real-time 20 Hz calibrated sensor streaming across 6 competitive Formula 1 cars, capturing extreme 355 km/h straight-line kinematics, 5.2G braking into Variante del Rettifilo, and 1,020°C carbon-carbon rotor thermal dynamics. The architecture spans: Virtual Physical Environment → 19 Calibrated Edge Sensors → CAN-FD Framing → WebSocket Gateway → Telemetry Ingestion Engine → Pitwall Dashboard → Automated Fault Diagnostics → Closed-Loop Engineering Intervention.

🏁 Multi-Device Dual Screen Architecture Setup

For academic examination and presentations to IoT faculty, this platform supports running the 3D race physics and the pitwall telemetry monitoring on two separate devices or browser windows simultaneously:

DEVICE A (DRIVER POV / 3D SIMULATION):
URL: http://localhost:8080/?mode=sim (Full 3D WebGL physics, cockpit views, track camera towers)
DEVICE B (PITWALL RACE ENGINEER MONITOR):
URL: http://localhost:8080/?mode=dashboard (Live gauges, 4-wheel matrix, sensor registry, fault injection)
Telemetry packets stream over the local WebSocket server on port 8080 at 20Hz. Any fault injected on Device B directly influences vehicle physics on Device A in real time!
